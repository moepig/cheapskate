# Web コンソール

本ドキュメントは、Web コンソールでの設定確認、スケジュールと override の変更、および公開時に必要なアクセス設定を説明する。

## 画面と確認できる内容

Web コンソールは任意で導入する管理インターフェースである。画面ごとの用途を、以下に示す。

| 画面 | 内容 |
| --- | --- |
| グループ一覧 | 保存済みのグループ設定と、無期限 override の設定 |
| グループ詳細 | グループ設定、リソースタグ、AWS の現在状態 |
| スケジュールフォーム | 起動・停止 cron の設定 |
| override フォーム | running・stopped・disabled と有効期限の設定 |

グループ詳細では、スケジュール、override、ECS 上限、所属タグ、およびリソース設定タグを確認できる。

現在状態の表示は読み取り専用である。画面を開く操作ではリソースを起動・停止しない。

## 設定変更

スケジュールフォームでは起動と停止の cron を両方指定する。

override フォームでは要求する状態を選び、期限付きなら Until を設定する。グループ詳細の Until は画面表示時刻の 2 時間後で初期化される。無期限にする場合は空欄にする。

日時の表示と入力には DEFAULT_TIMEZONE を使用する。未設定時は UTC である。

一覧からの override は無期限となる。

設定保存後は、後続の reconcile で AWS に反映される。画面を再表示し、設定と現在状態を確認する。

保存時に HTTP 409 が返った場合は、別の変更と競合している。再読み込みし、設定を確認してから必要な変更を再実行する。グループ設定の制約は、[グループ設定](group_config.md)を参照。

## 公開とアクセス設定

Web コンソールは認証機能を持たない。認証済み API Gateway などの ingress の背後へ配置し、アクセスを制限すること。公開するホストは ALLOWED_HOSTS に設定する。

要求の検査条件を、以下に示す。

| 検査対象 | 適用条件 | 許可条件 |
| --- | --- | --- |
| Host | 全要求 | ALLOWED_HOSTS に一致 |
| Sec-Fetch-Site | 変更フォームでヘッダーが存在 | same-origin または none |
| Origin | 変更フォームでヘッダーが存在 | 要求の Host と一致 |

未許可の Host やクロスオリジンの変更要求は拒否される。

ALLOWED_HOSTS の完全一致条件、BASE_PATH の転送方法、および待ち受けポートは、[実行時設定](config.md#web-コンソール)を参照。Lambda への配置は[セットアップ](setup.md)を参照。
