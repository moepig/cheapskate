# グループとスケジュール

cheapskate は、AWS リソースをグループにまとめ、スケジュールまたは override で指定した起動・停止状態を定期的に維持する。本ドキュメントは、グループの所属、要求する状態、および時刻による状態の決定を説明する。

## グループとリソースの所属

グループは、同じ起動・停止設定を適用するリソースの集合である。グループ設定は DynamoDB に保存し、各リソースの cheapskate:group タグに所属するグループ名を設定する。1 個のグループに複数のリソース種別を所属させられる。

設定と実際の状態の違いを、以下に示す。

| 情報 | 保存先または取得元 | 意味 |
| --- | --- | --- |
| グループ設定 | DynamoDB | 通常の起動・停止時刻、override、および ECS 台数上限 |
| リソース設定 | AWS リソースのタグ | 所属グループと、ECS の起動台数・通常の上下限・上下限管理モード |
| 現在状態 | AWS サービス | 現在の起動・停止状態や ECS のタスク数・スケーリング設定 |

CLI と Web コンソールの設定保存は、AWS リソースの起動・停止完了を意味しない。reconciler は、定期実行で設定と現在状態を比較し、必要な操作を行うプログラムである。

## スケジュール

スケジュールは、通常の起動時刻を示す start_cron と、停止時刻を示す stop_cron の組である。両方を 5 フィールドの cron で指定し、実行時設定 DEFAULT_TIMEZONE のタイムゾーンで解釈する。

各サイクルでは、直近の起動時刻と停止時刻のうち新しい側の状態を選ぶ。同時刻なら停止を選ぶ。稼働時間帯にグループを登録した場合も、次のサイクルから起動状態を選ぶ。

平日 09:00～18:00 に稼働する設定例を、以下に示す。

```text
start_cron: 0 9 * * 1-5
stop_cron: 0 18 * * 1-5
DEFAULT_TIMEZONE: Asia/Tokyo
```

## override

override は、スケジュールより優先する状態の指定である。無期限、または指定時刻まで有効な設定を作成できる。状態と動作の対応を、以下に示す。

| override | 動作 |
| --- | --- |
| running | 所属リソースを起動状態に保つ |
| stopped | 所属リソースを停止状態に保つ |
| disabled | 所属リソースの状態確認と起動・停止を行わない |

有効な override がなければスケジュールを使う。override の解除または失効後は、その時点のスケジュールに従う。disabled の設定自体は AWS リソースの状態を変更しない。

### 稼働時間の延長例

平日 09:00～18:00 のグループに、月曜日 17:00 から同日 20:00 までの running override を設定した場合の状態を、以下に示す。時刻は Asia/Tokyo とする。

| 時刻 | スケジュールによる状態 | override | 適用する要求 |
| --- | --- | --- | --- |
| 月曜日 09:00 | 起動 | なし | running |
| 月曜日 17:00 | 起動 | running が有効 | running |
| 月曜日 18:00 | 停止 | running が有効 | running |
| 月曜日 20:00 | 停止 | 失効済み | stopped |
| 火曜日 09:00 | 起動 | 失効済み | running |

20:00 以降のサイクルでは、18:00 の停止時刻に基づいて停止を選ぶ。実際の起動・停止は、その要求を読み取ったサイクルで始まる。
